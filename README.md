# Legal AI Assistant For Law Enforcement

This is an AI-powered assistant designed to help law enforcement personnel with legal queries and FIR (First Information Report) processing. The system uses RASA for conversational AI and includes comprehensive IPC (Indian Penal Code) section information.

## Features
- Conversational AI interface using RASA
- FIR processing and management
- IPC section lookup and information
- Database integration for storing case information
- Cyber crime data integration
- Comprehensive testing suite

## Setup
1. Install requirements: `pip install -r requirements.txt`
2. Set up the database using the provided schema files
3. Train the RASA model
4. Run the chat interface

## Project Structure
- `actions/`: Custom RASA actions
- `data/`: Training data and configurations
- `models/`: Trained RASA models
- `rasa/`: RASA core files
- `static/`: Static assets
- `tests/`: Test suite
- Database management and utility scripts
